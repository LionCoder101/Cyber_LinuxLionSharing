# Terraform Learning Roadmap

## Phase 1: Basics
- Understand what Terraform is
- Learn HCL syntax
- Learn the core workflow: init, plan, apply, destroy
- Practice with a local example

## Phase 2: Providers and Resources
- Learn how providers work
- Create resources in AWS
- Use variables and outputs
- Understand state files

## Phase 3: Intermediate Skills
- Organize code into modules
- Use remote state
- Work with variables and locals
- Use version control with Git

## Phase 4: Advanced Practice
- Build reusable modules
- Use CI/CD pipelines
- Secure secrets and credentials
- Apply best practices for production

## Recommended Weekly Plan
- Day 1-2: Learn Terraform basics
- Day 3-4: Practice with AWS resources
- Day 5-6: Learn variables, outputs, and state
- Day 7: Build a small project
