## Suggested Playlist Order
1. Terraform basics and installation
2. Providers and resources
3. Variables, outputs, and state
4. AWS deployment examples
5. Modules and best practices

## What to Watch For
- How Terraform compares with other IaC tools
- How to write HCL files correctly
- How to use `terraform plan` and `terraform apply`
- How to manage AWS resources safely

## Study and Teaching Plan
- Watch one beginner tutorial and take notes
- Recreate the example in your own environment
- Explain the concept out loud as if teaching a student
- Practice the same workflow again with a different resource
- Review the official docs after each lesson
